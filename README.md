# MEDORA

تطبيق ويب عربي RTL يعمل محلياً باستخدام IndexedDB. الملفات: `index.html`, `style.css`, `app.js` إضافة إلى ملفات PWA.

## التشغيل
1. ارفع محتويات المجلد إلى مستودع GitHub.
2. اربط المستودع مع Netlify أو GitHub Pages. لا تستخدم `file://` لأن IndexedDB وService Worker يحتاجان HTTPS أو localhost.
3. افتح رابط HTTPS مرة مع اتصال إنترنت، ثم من قائمة المتصفح اختر «إضافة إلى الشاشة الرئيسية» لتثبيته.
4. البيانات محفوظة في المتصفح على الجهاز نفسه. استخدم النسخة الاحتياطية JSON دورياً.

## ملاحظات مهمة
- تصدير PDF يفتح صفحة طباعة المتصفح؛ اختر «حفظ كملف PDF».
- تصدير CSV يفتح في Excel ويمكن استيراده كجدول.
- الاقتصاص المتقدم غير مدمج؛ يمكن قص الصورة من محرر الصور في الجهاز قبل اختيارها. يتم ضغط الصورة إلى JPEG مع حد أقصى 2200px.
- التطبيق نموذج محلي أولي، وليس بديلاً عن نظام صيدلي سحابي أو سجلات طبية معتمدة. لا يرسل البيانات لأي خادم. PIN حماية واجهة محلية وليس تشفيراً لقاعدة البيانات.
- بيانات تجريبية تُضاف يدوياً من الإعدادات، ولا توجد بيانات مرضى حقيقية ضمن المشروع.
